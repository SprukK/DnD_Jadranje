📱 How to write NFC stickers ▾
1
Install NFC Tools (free, iOS & Android).
2
Loot stickers: Write → Add record → Text → paste the GK:… code. Hold to sticker until confirmed.
3
App launcher sticker: Write → Add record → URL → paste your GitHub Pages URL. Hold to sticker. When players tap it, the browser opens the app directly.
4
Test each sticker after writing — tap with phone to confirm. Loot stickers show GK: text. App sticker opens the browser.
5
iPhone offline setup: Players open the app URL once at home (with wifi), then tap Share → Add to Home Screen. Works offline on the boat.
